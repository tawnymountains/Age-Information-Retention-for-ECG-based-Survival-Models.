# Uploading this release

This folder is self-contained. Do not upload its parent folder, private packaging scripts, the research workspace or the Overleaf project. No push, repository creation or public publication is performed by this package.

## Upload to the new repository

Target: [tawnymountains/ecg-age-retention](https://github.com/tawnymountains/ecg-age-retention).

1. Open the target repository and click **uploading an existing file**, or **Add file → Upload files** if files are already present.
2. Upload the **contents** of this folder, including `.github/` and `.gitignore`, not the ZIP itself as the only repository file.
3. If the repository name or owner changes, update the repository URLs in `pyproject.toml`, `CITATION.cff` and documentation before tagging a release.
4. Check that the README images render and the CI job passes. Review coauthor and dataset obligations before making the repository public.
5. Create a version tag/release such as `v0.2.0` when you choose to publish.

The earlier SMS repository is historical and is not the upload target for this package. No changes to that repository are required.

## Optional GitHub Pages gallery

The gallery has no external scripts and can be opened locally as `docs/index.html`.
To host it on GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/docs`, and save. No automatic Pages deployment is enabled here. After successful deployment, the expected URL is `https://tawnymountains.github.io/ecg-age-retention/`; this package does not assert that the site is already live. The gallery’s CSV links use a sibling copy in `docs/results/`, generated by the rendering script, so the same gallery works under a repository subpath. The repository-guide link points to GitHub. Markdown documentation remains readable as plain source when opened from a basic static host.

## Before publishing

- Review `docs/RELEASE_NOTES.md`, especially the two artifact-versus-draft discrepancies.
- Confirm authorship, license, release date and repository URL.
- Keep `null` training settings visibly unpublished; do not claim full study reproduction.
- Confirm the release contains no clinical records, checkpoints or private paths.
- Run the quick-start checks. The CI workflow is provided but hosted GitHub execution is only tested after upload.
